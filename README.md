# NTAG 424 DNA 巡检标签发卡与运维工具

基于 Python 3 + PySide6 开发的跨平台桌面发卡与运维工具，专用于配合 **ACS ACR122U** 读写器，为巡检场景下的 **NTAG 424 DNA** 标签提供**单卡调试与只读诊断**、**批量密钥注入（Provisioning）**与**一键恢复出厂初始化（Factory Reset）**。

---

## 一、 整体操作流程与界面架构

为避免配置与发卡操作混杂，工具采用清晰的分层工作流设计：

### 1. 🎮 生产作业台 (Workstation)
* **当前生效配方摘要条**：实时展示当前生效的算法引擎、盐值策略、MAC Key 及 URL 模板，支持一键快捷跳转调整或快速导入导出。
* **作业模式切换**：
  * **🎯 单卡手动模式（默认）**：
    * 放置卡片自动感应并显示卡片硬件 UID（如 `🟢 046C2822E57580 (准备就绪)`）。
    * 提供 3 个独立大按钮：
      * `[⚡ 注入发卡]`：对当前卡片写入配方密钥与 SDM。
      * `[🔄 恢复出厂]`：清空 SDM 并还原为全 00 密钥。
      * `[🔍 读取诊断]`：只读检测卡片当前 NDEF 记录与密钥认证状态，不破坏卡内任何数据。
    * 安全防呆，杜绝误写。
  * **🚀 批量自动模式**：
    * 适合流水线大批量连续发卡，选择动作（发卡注入 / 恢复出厂）后点击 `[▶ 启动批量作业流水线]`。
    * 即贴即写，单卡仅需 ~350ms，带声光蜂鸣器反馈与防重复刷写机制。
* **作业明细与诊断**：
  * 实时作业记录表（时间、UID、操作、状态、Key MAC 指纹、耗时）。
  * 实时 APDU 通信诊断日志窗口，方便排查底层卡片交互。

### 2. ⚙️ 配方与规则设定 (Configuration)
* **📋 基础发卡配方与 KDF 规则**：
  * 系统主密钥 (Master Key) 与随机生成
  * KDF 算法引擎（HKDF-SHA256、AES-128-CMAC、HMAC-SHA256、固定静态密钥）
  * 盐值来源策略（UID 字符串、UID 原始字节、自定义项目盐值、无盐值）
  * 派生上下文规则模板（支持 `{UID}`、`{SLOT}` 宏定义占位符）
  * 实时推算预览沙箱（自动根据输入推算 Slot 0 与 MAC 槽位 Key）
  * SDM 认证密钥选择（Key 1..4）
  * 巡检 URL 模板输入与偏移量自动计算
* **📁 文件权限矩阵**：
  * File 02 (NDEF & SDM SUN 动态镜像及访问权限)
  * File 01 (CC 描述文件锁定)
  * File 03 (私有扩展数据文件保护)
* **⚙️ 系统与硬件选项**：
  * Key Version 版本号轮换
  * ACR122U 蜂鸣器与 LED 声光开关
* **配方导入导出**：
  * `[📥 导入配方文件]` / `[📤 导出配方文件]`，支持以标准 JSON 格式在不同工作站或项目之间流转。

## 二、 快速启动

### 1. 运行环境要求
* macOS / Windows / Linux
* Python 3.10+
* 驱动支持：
  * **macOS / Windows**：系统已自带 PC/SC 智能卡驱动服务，直接插入 ACR122U 即可识别。
  * **Linux**：需确保已安装 `pcscd`（例如 `sudo apt install pcscd libccid`）。

### 2. 一键启动
在项目根目录下执行：
```bash
./run.sh
```
或者手动运行：
```bash
.venv/bin/python app.py
```

## 三、 单卡与批量使用场景说明

### 场景 A：单卡调试与新标签验货
1. 打开软件，默认停留在 **🎮 生产作业台** 的 **【🎯 单卡手动模式】**。
2. 将卡片放置在 ACR122U 感应区，界面显示 `🟢 已感应到卡片 UID: xxxxxxxx`。
3. 点击 **【🔍 读取诊断】**：
   - 查看卡片当前状态（是出厂默认状态、还是已发卡、或被未知密钥锁定），并查看卡内当前 NDEF 内容。
4. 如需写入，点击 **【⚡ 注入发卡】**，写入成功后蜂鸣器短响一声，表格增加一条记录。

### 场景 B：流水线大批量发卡
1. 在顶部配方栏确认当前配方无误（如需修改可点击【⚙️ 调整配方】）。
2. 在模式栏切换至 **【🚀 批量自动模式】**。
3. 点击 **【▶ 启动批量作业流水线】**。
4. 作业人员逐一把卡片贴在读卡器感应区：
   - 听到短促“哔”声，指示灯变绿，表示注入成功；
   - 拿开卡片，放入下一张；
5. 发卡完毕后点击 **【⏸ 暂停】**，点击 **【导出批次清单 (CSV)】** 保存发卡台账。
