# NTAG424 Pro - NTAG 424 DNA 标签发卡与运维工具 (ntag424-pro)

基于 Python 3 + PySide6 开发的专业级跨平台桌面发卡与运维工具，专用于配合 **ACS ACR122U** 读写器，为巡检、防伪及资产数字化场景下的 **NTAG 424 DNA** 标签提供**单卡调试与只读诊断**、**批量发卡注入（Provisioning）**与**一键恢复出厂初始化（Factory Reset）**。

---

## 一、 整体操作流程与界面架构

为避免配置与发卡操作混杂，工具采用清晰的分层工业工作流设计：

### 1. 生产作业台 (Workstation)
* **当前生效配方摘要条**：实时展示当前生效的配方名称、算法引擎、盐值策略、MAC 槽位及 URL 模板，支持一键打开【配方详情】查看或【调整配方】快速导入导出。
* **作业模式切换**：
  * **单卡调试模式（默认）**：
    * 放置卡片自动感应硬件 UID（如 `🟢 卡片已就绪: 048C2822E57580`）。
    * 提供 3 个独立大按钮：
      * `[发卡注入]`：对当前卡片写入派生密钥与 NDEF SDM 动态签名。
      * `[恢复出厂]`：清空 SDM 并将所有密钥还原为出厂默认全 00 密钥。
      * `[读取诊断]`：只读检测卡片当前认证状态与 NDEF 记录，不破坏卡内任何数据。
    * 安全防呆，杜绝误写。
  * **批量自动模式**：
    * 适合流水线大批量连续发卡，选择动作（批量发卡注入 / 批量恢复出厂）后点击 `[启动批量作业]`。
    * 即贴即写，单卡仅需 ~350ms，带声光蜂鸣器反馈与防重复刷写机制。
* **作业执行记录与通信诊断**：
  * 实时作业执行记录表（时间、UID、作业类型、状态、主控 Key 0、SDM 签名 Key、NDEF 模板、耗时、详细说明），支持一键导出 CSV 台账。
  * 实时 APDU 通信诊断日志窗口，方便排查底层卡片交互。

### 2. 硬件设备管理 (Hardware)
* 实时监控系统 PC/SC 智能卡子系统；
* 自动识别连接的 ACS ACR122U 物理读卡器；
* 提供声光反馈测试与自动蜂鸣器控制选项。

### 3. 发卡配方配置 (Configuration)
* **密钥派生与 SDM 规则**：
  * 系统主密钥 (Master Key) 与随机生成
  * KDF 算法引擎（HKDF-SHA256、AES-128-CMAC、HMAC-SHA256、固定静态密钥）
  * 派生盐值来源（UID 字符串、UID 原始字节、自定义项目盐值、无盐值）
  * 派生上下文 (Info Context) 模板（支持 `{UID}`、`{SLOT}` 变量占位符）
  * SDM 认证密钥选择（Key 1..4）
  * NDEF 动态 URL 模板与 Android AAR 记录追加注入
  * 动态偏移与容量实时解析（精确计算 UID/CTR/CMAC 偏移与 File 02 容器容量用量）
  * 出厂验证密钥 (Factory Key)
* **文件安全访问权限**：
  * File 02 (NDEF 交互文件 256 字节 - SUN 动态镜像与访问权限控制)
  * File 01 (CC 描述文件 32 字节配置锁定)
  * File 03 (私有扩展文件 128 字节保护)
* **配方导入导出**：
  * 支持以标准 JSON 格式在不同工作站或项目之间流转与归档。

## 二、 快速启动

### 1. 运行环境要求
* macOS / Windows / Linux
* Python 3.10+
* 驱动支持：
  * **macOS / Windows**：系统已自带 PC/SC 智能卡驱动服务，直接插入 ACR122U 读卡器即可自动识别。
  * **Linux**：需确保已安装 `pcscd`（例如 `sudo apt install pcscd libccid`）。

### 2. 安装与运行
在项目根目录下执行：
```bash
# 赋予启动脚本执行权限并启动
./run.sh
```
或者手动运行：
```bash
# 创建并激活虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 启动图形应用
python app.py
```

## 三、 单卡与批量使用场景说明

### 场景 A：单卡调试与新标签验货
1. 打开软件，默认停留在 **生产作业台** 的 **【单卡调试模式】**。
2. 将卡片放置在 ACR122U 感应区，界面显示 `● 卡片已就绪: 048C2822E57580`。
3. 点击 **【读取诊断】**：
   - 查看卡片当前状态（出厂默认状态、匹配当前系统配方、或被未知密钥锁定），并查看卡内当前 NDEF 内容与 AAR 记录。
4. 如需写入，点击 **【发卡注入】**，注入成功后蜂鸣器短响一声，表格增加一条台账记录。

### 场景 B：流水线大批量发卡
1. 在顶部配方栏确认当前配方无误（如需修改可点击【调整配方】）。
2. 在模式栏切换至 **【批量自动模式】**。
3. 点击 **【启动批量作业】**。
4. 作业人员逐一把卡片贴在读卡器感应区：
   - 听到短促“哔”声，指示灯变绿，表示注入成功；
   - 拿开卡片，放入下一张；
5. 发卡完毕后点击 **【暂停批量作业】**，点击 **【导出 CSV】** 保存发卡批次台账。
